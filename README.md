#Automatic Plant Watering System
#I want to build an automatic plant-watering system that can keep my plants watered for extended periods while I am away from home.
#For the first version, I want to water a single plant using one water pump controlled by a relay. The relay will be triggered based on measurements from a single soil moisture sensor connected to an #ESP8266 microcontroller.
#The ESP8266 should connect to my Wi-Fi router. When I access the ESP8266 through a web browser, it should provide a graphical user interface (GUI) for monitoring the current soil moisture readings.
#The interface should allow me to configure the following parameters:
#Soil moisture thresholds: Adjustable wet and dry threshold values to determine when watering should start and stop.
#Watering duration: An adjustable duration for each watering cycle.
#Watering intervals: Adjustable intervals between watering cycles.
#The system should operate automatically according to the configured parameters, without requiring manual intervention while I am away from home.
